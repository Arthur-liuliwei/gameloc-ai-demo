# GameLoc AI Demo
https://gameloc-ai-demo.vercel.app/

AI-assisted game localization workflow demo built with Next.js, React, TailwindCSS, and OpenAI.

## Overview

GameLoc AI Demo is a lightweight localization production workflow prototype designed to simulate how AI can assist localization producers, reviewers, and translators in modern game development pipelines.

The project focuses on:

- AI-assisted translation
- Glossary enforcement
- Context-aware localization
- Human review workflow
- Localization QA
- Constraint-aware UI localization
- Excel export pipeline

This demo was built as both:
- a technical learning project for AI-assisted localization tooling
- a portfolio piece for localization production and localization technology roles

---

## Features

### Translation Workspace
- Card View for detailed string review
- List View for production-scale operations
- Batch translation workflow
- Human review pipeline

### Glossary Management
- Add/edit/delete glossary terms
- Required / Preferred / Forbidden terminology
- Inline glossary creation from selected text
- Glossary compliance checking

### AI Prompt Presets
- AAA Cinematic
- Riot-style MOBA
- Fantasy RPG
- Casual Mobile

### Localization QA
- Placeholder validation
- Glossary inconsistency detection
- Machine-translation tone detection
- UI overflow risk detection

### Constraint-Aware Localization
- Character limit enforcement
- UI context metadata
- Skill-name length constraints
- Context-aware grouped translation

### Export Pipeline
- Translation Workspace Excel export
- Glossary Excel export

## Project Philosophy

The goal of this project is not to replace human localization.

The objective is to:
- improve localization consistency
- reduce repetitive operations
- accelerate review workflows
- proactively reduce UI localization risks
- support localization producers with AI-assisted tooling

This project especially focuses on real production concerns often encountered in AAA and live-service game localization:
- terminology consistency
- UI overflow/clipping
- contextual translation consistency
- naming conventions
- review workflows
- scalable localization operations
